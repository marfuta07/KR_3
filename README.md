# Данные о самолетах

## Описание

Этот проект представляет собой систему для сбора и анализа данных о воздушных судах в реальном времени. Проект использует открытые API для получения информации о самолетах, находящихся в воздушном пространстве различных стран, и сохраняет эти данные в базу данных PostgreSQL для последующего анализа.

### Основные возможности

- 📍 Получение координат стран через Nominatim API
- ✈️ Сбор данных о самолетах через OpenSky Network API
- 💾 Сохранение данных в PostgreSQL
- 📊 Анализ данных через DBManager
- 🔍 Поиск самолетов по ключевым словам в позывном
- 📈 Статистика по странам и скорости

## Цели и задачи

Целью проекта является создание системы для мониторинга и анализа авиационного трафика с использованием:

- Абстрактных контрактов для API (через ABC и @abstractmethod)
- Строгой валидации входных данных
- Корректной обработки ошибок сети и API
- Преобразования "сырых" данных от внешних сервисов в структурированные объекты
- Разделения логики на модули (Database, APIClient, DBManager)
- Полного покрытия документацией

## Технологии

- **Python 3.8+** - основной язык программирования
- **PostgreSQL** - реляционная база данных
- **OpenSky Network API** - получение данных о самолетах
- **Nominatim API** - получение координат стран
- **psycopg2** - работа с PostgreSQL
- **requests** - HTTP-запросы к API
- **python-dotenv** - управление переменными окружения

## Примеры использования функций:
Модули
+ config.py
Файл конфигурации, содержащий:

Параметры подключения к БД

DSN строку

Список стран для мониторинга

+ database.py
Класс Database для работы с PostgreSQL:

connect() - подключение к БД

create_tables_if_not_exists() - создание таблиц

clear_data() - очистка данных

insert_country() - вставка страны

insert_aeroplane() - вставка самолета

+ api_inf.py
Класс APIClient для работы с API:

get_country_coordinates() - координаты через Nominatim

get_aeroplanes_by_bounding_box() - самолеты через OpenSky

+ db_manager.py
Класс DBManager для аналитики:

get_countries_and_aeroplanes_count() - статистика по странам

get_all_aeroplanes() - список всех самолетов

get_avg_speed() - средняя скорость

get_aeroplanes_with_higher_speed() - самолеты выше средней скорости

get_aeroplanes_with_keyword() - поиск по ключевому слову

+  interfaces.py
Абстрактные классы для реализации SOLID:

DataStorage - интерфейс для хранилищ данных

DataSource - интерфейс для источников данных

DataAnalyzer - интерфейс для анализа данных
